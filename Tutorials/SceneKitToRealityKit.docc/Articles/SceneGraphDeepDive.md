# SceneKit 심화 — 노드 트리로 만드는 닫힌 세계

Chapter 1에서 본 C3 섬이 씬 그래프 위에서 실제로 어떻게 조립되는지, 참고용으로 자세히 정리한다.

## 핵심 모델: 씬 그래프

`SCNScene`은 하나의 `rootNode`를 가지고, 모든 `SCNNode`는 그 아래에 부모-자식 관계로 매달린다. 부모 노드의 변환(position·rotation·scale)은 자식에게 그대로 이어진다. C3 섬에서 나무·바닥·조명이 섬 노드의 자식으로 붙어 있으면, 섬 노드 하나만 옮겨도 그 안의 모든 것이 함께 움직인다.

## 좌표를 읽는 법

같은 점이라도 어떤 노드를 기준으로 하느냐에 따라 숫자가 달라진다.

| 하고 싶은 일 | 쓰는 메서드 |
| --- | --- |
| 자식 노드의 로컬 좌표를 씬 전체(월드) 좌표로 바꾸기 | `node.convertPosition(_:to: nil)` |
| 월드 좌표를 특정 노드의 로컬 좌표로 바꾸기 | `node.convertPosition(_:from: nil)` |
| 한 노드의 좌표를 다른 노드 기준으로 바꾸기 | `convertPosition(_:to:)` / `convertPosition(_:from:)`에 대상 노드 전달 |

C3에서 돼지의 위치를 하드코딩한 숫자는 섬 노드 기준 로컬 좌표다. 카메라가 섬 주위를 돌아도 이 숫자는 바뀌지 않는다 — 씬 그래프가 곧 좌표의 기준이기 때문이다.

## 노드에 붙는 것들

하나의 `SCNNode`는 여러 책임을 동시에 짊어질 수 있다.

| 요소 | 책임 |
| --- | --- |
| `geometry` (`SCNGeometry`) | 눈에 보이는 형태 |
| `materials` | 표면의 색·질감 |
| `camera` (`SCNCamera`) | 이 노드 위치에서 본 장면을 렌더링 |
| `light` (`SCNLight`) | 조명 기여 |
| `physicsBody` | 물리 시뮬레이션 참여 여부 |
| `actions` | 시간에 따른 변환 애니메이션 |
| `particleSystems` | 파티클 효과 |

이 목록이 한 클래스에 모여 있다는 사실이, Chapter 4에서 Entity-Component-System과 비교할 때의 기준점이 된다.

## 모양, 물리, 행동을 한 번에 읽기

노드를 디버깅할 때는 세 가지를 함께 확인해야 한다. geometry가 있어야 보이고, physicsBody가 있어야 충돌·중력에 반응하며, action이 실행 중이어야 움직인다. 셋 중 하나만 빠져도 "안 보인다", "안 움직인다", "뚫고 지나간다" 같은 증상으로 나타난다. action과 물리 시뮬레이션을 동시에 같은 노드에 걸면 위치가 서로 충돌할 수 있으므로, 이동은 둘 중 하나로 통일한다.

## 에셋을 노드로 가져오는 과정

USD(`.usdc`) 자산을 불러올 때는 좌표계 변환과 스케일 정규화가 필요할 수 있다. 로더는 자산을 찾지 못하면 조용히 실패하는 대신, 확인 가능한 폴백(예: 색이 다른 대체 지오메트리)을 두어 "자산이 없다"와 "자산이 잘못 배치됐다"를 구분할 수 있게 한다.

## SwiftUI 안에서 SceneKit을 사용하는 구조

`UIViewRepresentable`로 `SCNView`를 감싸면 SwiftUI 쪽에서는 뷰의 생명주기만 관리하고, 순수 노드 구성 로직은 별도 타입으로 분리할 수 있다. 탭 제스처는 `SCNView.hitTest`로 화면 좌표 아래에 있는 노드를 찾는다 — 이때 찾아지는 것은 항상 **씬에 선언된 노드**이며, 화면에 비친 실제 사물이 아니다.

## 자주 생기는 오해와 디버깅 질문

| 증상 | 먼저 의심할 것 |
| --- | --- |
| 노드가 안 보인다 | geometry·material 누락, 카메라 프러스텀 밖 위치 |
| 탭해도 반응이 없다 | hitTest 대상 노드 이름 불일치, 다른 노드가 앞을 가림 |
| 위치가 예상과 다르다 | 로컬 좌표와 월드 좌표 혼동 |
| 물리 반응이 없다 | `physicsBody` 누락, 충돌 카테고리 설정 오류 |
| 액션이 안 끝난다 | 완료 핸들러 미호출, action key 충돌 |
