최신 문장·준비 과정·화면 편집과 새 Xcode 앱 설정 검증은 [초보 독자 편집 기록](beginner-tutorial-editing.md)을 따른다. 아래는 최초 피드백 개선 당시의 기록이다.

작성: 2026-09-19. 범위: 학습용 DocC와 웹 읽기 페이지. 본편 앱 Task 6–7 및 Chapter 2–4의 구현 범위는 변경하지 않는다.

## 피드백을 반영한 결정

| 지적 | 변경 | 확인 방법 |
| --- | --- | --- |
| 문장이 길고 지금 할 일을 찾기 어렵다 | 파일 이름과 행동을 제목에 먼저 쓰고, 실행 확인·막혔을 때의 조치를 분리했다 | 기본 실습의 모든 단계에서 행동과 성공 기준을 확인한다 |
| 필요한 지식과 시간이 너무 많다 | 기본 실습에서는 위치와 탭 이동만 다룬다. 방·카메라·모델 로더는 준비 파일로 제공하고 내부 구현은 선택 학습으로 옮겼다 | 독자가 고치는 파일은 ContentView.swift 하나이며, 최종 파일은 15줄이다 |
| 그대로 따라 해도 만들기 어렵다 | Starter 두 파일, 단계별 전체 정답, 변경 줄 강조, 실제 실행 화면을 제공한다 | 다운로드 ZIP에서 추출한 자료로 세 단계 모두 빌드·실행했다 |
| 직접 따라 해 봤는지 검증이 필요하다 | 화면 표시 → 왼쪽으로 위치 변경 → 탭 이동을 각각 실행해 촬영했다 | 아래 재현 기록과 원본 스크린샷으로 확인한다 |

직전 개선본의 필수 경로는 19개 단계·14개 코드 버전·9개 편집 파일이었다. 현재 기본 경로는 준비와 마무리를 포함해 **7개 단계·3개 코드 버전·1개 편집 파일**이다. 예전 전체 경로는 `01-ClosedWorld-Details.tutorial`에 선택 학습으로 보존했다. 노드 구조를 살펴보는 Chapter 1의 추가 학습 목표는 이 경로에서 다룬다.

이 결정은 [기존 가독성 조사](tutorial-readability-research.md)의 절차 중심 글쓰기와 작은 행동 뒤 결과 확인 원칙을 이어간다. 개념을 모두 먼저 설명하는 대신, 독자가 한 가지를 바꾸고 결과를 확인하도록 구성했다.

## 다운로드 자료 실행 결과

환경: Xcode 26.6, Swift 6.3.3, iPhone 17 Pro 시뮬레이터 / iOS 26.5. 임시 앱의 최소 타깃은 iOS 17, Swift 6이다.

1. `prepare_rehearsal.py`로 실제 `ClosedWorld-QuickStart.zip`에서 준비 코드, 모델, 세 단계의 정답을 추출했다. 임시 디렉터리에 새 SwiftUI 진입점과 Xcode 프로젝트를 만들었다.
2. 1단계 정답으로 빌드·설치·실행했다. 방 앞쪽 가운데에 돼지가 나타났다.
3. `ContentView.swift`만 2단계 정답으로 바꾸고 다시 빌드·실행했다. 돼지가 왼쪽에서 시작했다.
4. 같은 파일을 3단계 정답으로 바꾸고 다시 빌드·실행했다. 시뮬레이터의 방 안을 누르자 돼지가 소파 뒤로 이동했다.

| 확인점 | 결과 | 실제 실행 화면 |
| --- | --- | --- |
| 장면 표시 | 빌드·설치·실행 통과 | [가운데의 돼지](../Guides/SceneKitToRealityKit.docc/Tutorials/Resources/quickstart-01-show.jpg) |
| pigX: -1.5 | 빌드·설치·실행 통과 | [왼쪽의 돼지](../Guides/SceneKitToRealityKit.docc/Tutorials/Resources/quickstart-02-position.jpg) |
| onTapGesture 이동 | 빌드·설치·탭 후 이동 확인 | [소파 뒤의 돼지](../Guides/SceneKitToRealityKit.docc/Tutorials/Resources/quickstart-03-move.jpg) |

위 사진은 이 자료로 실행한 앱에서 촬영했다. 웹에서는 장면이 있는 가운데 부분을 보여 주고, 크게 보기 링크로 촬영한 전체 화면을 열 수 있다. 돼지가 소파에 완전히 가려지는 예제가 아니라는 점도 본문에 적었다.

- 경고를 오류로 처리한 DocC 변환 통과. 기본 실습과 선택 학습 모두 생성됐다.
- 기본 3개·선택 5개 실행 구간의 iOS 시뮬레이터 SDK 타입 검사 통과.
- 다운로드 ZIP의 Swift 파일과 원본 일치, 기본 페이지의 코드 3개와 원문 일치, 로컬 자산·앵커 검사 통과.
- 웹 빌드와 기존 서버 폴백 테스트 통과. 읽기 페이지 스크립트 문법 검사 통과.
- 1280px 데스크톱·390px 모바일 폭에서 문서 가로 넘침 없음. 목차 이동, 변경 줄 강조, 선택 학습 링크를 확인했다. 2단계 전체 복사 후 검증용 입력란에 실제 붙여 넣어 229자 원문과 일치하는 것을 확인했다.

## 아직 검증하지 않은 것

이 기록은 배포 자료의 빌드·실행 재현성 검증이다. Xcode 새 프로젝트·파일 추가의 모든 클릭을 처음 배우는 사람이 설명 없이 수행하는 테스트는 아니다. 준비 과정의 사용자 동작은 임시 프로젝트 생성으로 대신했으므로, 이를 초보자 완주 검증으로 보고하지 않는다.

20–30분은 기본 실습의 예상 시간이며 Xcode 설치는 제외한다. 초보자의 실제 소요 시간을 측정한 값이 아니다. SwiftUI 기본 화면을 읽을 수 있는 독자를 대상으로 한다.

첫 독자 검증은 아래 기준으로 진행한다. 설명자는 막힌 위치를 기록하고, 도움을 주기 전까지 독자가 문서만으로 해결할 수 있는지 관찰한다.

| 구간 | 기록할 내용 | 통과 기준 |
| --- | --- | --- |
| 준비 | 파일 추가·실행 대상에서 막힌 위치, 도움 횟수 | 문서와 ZIP만으로 기본 앱 실행 |
| 장면·위치 | 소요 시간, 코드 붙여 넣기·수정 실수 | 가운데와 왼쪽 결과를 구분 |
| 탭 이동 | 막힌 문장, 중괄호·재실행 혼동 | 탭 후 이동을 재현 |
| 마무리 | 독자의 설명을 그대로 기록 | 현실의 소파 위치를 이 앱이 모르는 이유를 설명 |

멈춘 지점이 나오면 먼저 해당 단계의 문장·화면·복구 안내를 수정하고, 다음 독자로 다시 확인한다. 아직 실제 참여자의 결과는 없다.

## 게시 상태

개선본은 로컬에서 검증했다. 기존 소유자 전용 사이트에 전송하는 작업은 이전 자동 승인 심사에서 거부됐으며, 이후 게시 승인이 없으므로 이번에도 외부로 전송하지 않았다. 게시 후 공유 링크에서 내려받기와 실습 경로를 다시 확인해야 한다.
