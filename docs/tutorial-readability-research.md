# Chapter 1 튜토리얼 가독성 개선

작성: 2026-09-19. 범위: 학습용 DocC 콘텐츠와 이를 보여 주는 웹페이지. 본편 앱 Task 6 리뷰·Task 7 구현 상태와 Chapter 2–4 범위는 변경하지 않는다.

이 문서는 첫 가독성 개선의 조사·구현 기록이다. 이후 독자 피드백을 반영해 기본 경로를 7단계로 줄이고, 아래의 19단계 경로를 선택 학습으로 옮겼다. **현재 구성과 검증 결과는 [피드백 대응 기록](tutorial-feedback-validation.md)을 따른다.**

## 발견한 문제

- 첫 코드가 아직 소개하지 않은 HideAction을 참조했고 SwiftUI 진입점은 없었다. 독자가 순서대로 붙여 넣어도 중간 실행이 불가능했다.
- 프로젝트 생성, 파일 이름, 새 파일과 전체 교체의 구분, 모델 확보·번들 추가 방법이 빠져 있었다.
- 한 Step의 두 @Code 중 두 번째 코드는 렌더 JSON에 포함되지 않았다. 조립 코드 ClosedWorld가 웹에서 누락됐다.
- NodeInspector는 호출되지 않았고, 물리 설정·키 있는 액션도 없는 상태에서 세 기능을 볼 수 있다고 설명했다.
- 모델과 참고 화면이 개인 프로젝트에 의존했고, 사진 속 섬은 실습 결과인 방과 달랐다.
- 문장이 추상적인 개념 설명에 집중해, 지금 할 일과 성공 기준을 빠르게 찾기 어려웠다.

## 선택한 구성

- 웹 루트는 8개 구간·19개 단계의 실습 안내 페이지. 데스크톱은 목차와 본문, 모바일은 본문 위의 줄바꿈 가능한 목차를 사용한다.
- 본문은 16–18px, 넉넉한 줄 간격과 읽기 폭을 사용한다. 작업 지시, 성공 기준, 문제 해결을 시각적으로 구분한다.
- 코드 14개는 한 단계에 한 파일만 둔다. 긴 코드는 접어 둘 수 있으며 전체 복사는 접힘 상태와 무관하게 정확한 원문을 복사한다.
- 설명 원본은 DocC 하나로 유지한다. `tools/tutorial_site/render.py`가 컴파일된 JSON을 읽으므로 웹 본문을 따로 편집하지 않는다. 기존 `/tutorials/` 경로도 유지한다.
- 새 Xcode 앱에서 따라 하는 독립 실습을 제공한다. 본편의 Tuist 구성을 변경하지 않는다.
- 실습 자료 ZIP은 다섯 구간의 전체 소스와 승인된 원본 Piggy.usdc를 포함한다. 여러 구간을 동시에 프로젝트에 추가하면 안 된다는 복구 안내를 포함한다.
- 모델 없는 분홍 상자 경로도 끝까지 컴파일할 수 있다. 실제 모델은 선택적으로 추가한다.

## 실행 검증에서 수정한 문제

- Piggy.usdc에는 별도 Camera가 들어 있다. 실제 실행 시 이 카메라가 선택되어 검은 화면과 확대된 일부 표면만 보였다. `SCNView.pointOfView`에서 루트 바로 아래 실습용 Camera를 명시해 해결했다.
- 원본 모델은 Z-up이다. 승인된 재사용 원본 `C3_Piggy/C3_Piggy/Scene/PigController.swift`의 회전 방식(X축 +90°, Z축 180°)을 적용한 뒤 하위 geometry 경계를 합산해 정규화한다.
- 소파 중앙으로 이동하며 모델의 바닥 보정 높이를 잃던 액션은 현재 y를 유지하고 소파 뒤쪽 좌표로 이동하도록 바꿨다. 연속 탭은 같은 `hide` 키로 교체한다.
- 카메라는 앞쪽 벽 너머로 방을 내려다본다. 화면은 실제 가려짐을 구현한 예제가 아니며, 이동 후에도 몸이 보일 수 있다고 명시한다.
- 노드 관찰은 실제 호출을 연결하고 부모 geometry·하위 geometry 수·없을 수 있는 physicsBody·키 있는 action을 구분한다.

## 검증과 한계

- 경고를 오류로 처리한 독립 DocC 변환 통과.
- 다섯 실행 구간을 각각 iOS 17 시뮬레이터 대상으로 Swift 타입 검사.
- 다운로드 ZIP과 소스 일치, HTML의 14개 복사 코드 원문 일치, 로컬 자산·앵커 검사.
- 웹 빌드와 기존 서버 폴백 테스트 통과.
- 데스크톱에서 목차 이동·코드 펼치기·복사 성공 안내 확인. 390px·640px 폭에서 문서의 가로 넘침 없음.
- iPhone 17 Pro / iOS 26.5 시뮬레이터에서 마지막 구간 앱을 빌드·설치·실행하고 화면 탭에 따른 이동 확인. 그 결과 스크린샷을 본문에 추가했다.
- 각 중간 구간은 타입 검사했으며 모든 구간의 시뮬레이터 화면을 개별 촬영한 것은 아니다. 초보 독자 대상 사용성 테스트와 전체 접근성 적합성 검증은 별도다.

## 게시 상태

사이트 로컬 변경은 `ece0605`에 기록했다. 기존 소유자 전용 사이트 저장소로의 전송이 자동 승인 심사에서 거부되어 원격 전송·버전 저장·배포는 수행하지 않았다. 사용자가 해당 사이트로 문서·코드·모델을 전송하고 게시하는 데 동의하면 기존 사이트 ID와 접근 범위를 유지해 게시한다. 자격 증명은 저장소에 기록하지 않는다.
