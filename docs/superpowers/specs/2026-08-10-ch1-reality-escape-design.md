# Chapter 1 — C3 월드에서 현실 세계로 탈출하기 설계

## 배경

기존 Chapter 1의 단순 방·가짜 소파 장면은 Draft PR의 기준선으로 남긴다. 이 설계는 그 장면을 C3_Piggy의 SceneKit 월드로 교체하고, 가짜 나무 뒤에 숨은 돼지가 카메라 회전에 의해 드러난 뒤 RealityKit의 실제 공간으로 넘어가는 체험을 정의한다.

## 목표

사용자는 먼저 코드로 구성된 C3_Piggy 월드를 회전 카메라로 살핀다. 돼지가 기존 나무 뒤로 걸어가 숨으려 해도, 사용자가 카메라를 돌리면 즉시 드러난다. 돼지는 현실 세계로 넘어가고, 사용자가 직접 지정한 실제 물체의 반대편으로 이동한다. LiDAR가 재구성한 실제 메쉬가 돼지를 가리므로, 사용자는 실제로 다른 위치로 움직여야 돼지를 다시 찾을 수 있다.

## 범위와 제외 범위

### 포함

- C3_Piggy의 SceneKit 3D 월드 표현: 섬, 기존 나무, 돼지의 정지·걷기·놀람 모델, 카메라 회전·줌, 조명, 에셋 로딩과 걷기 애니메이션
- 돼지 나레이션, 탭으로 시작하는 가짜 숨기, 카메라 회전으로 발견되는 장면
- 카메라 권한 요청을 포함한 SceneKit → RealityKit 자동 전환
- iOS LiDAR 실기기의 ARKit 평면·메쉬 재구성과 RealityKit 오클루전
- 사용자가 실제 물체의 세로 면을 탭해 숨을 곳을 지정하는 인터랙션
- Chapter 1 DocC·프로젝트 컨텍스트·인수인계 갱신

### 제외

- C3_Piggy의 금융 로직, SwiftData 저장소, 용돈 관리, WatchConnectivity, Watch 앱과 관련 화면
- 자동으로 물체의 의미를 판별하는 분류 UX. 사용자가 실제 물체를 직접 탭한다.
- LiDAR가 없는 기기에서 실제 물체 오클루전을 흉내 내는 대체 기능
- Chapter 2 이후의 상세 구현과 문서 배포

## 경험 흐름

```text
openingNarration
  → readyForPigTap
  → walkingBehindTree
  → hiddenInClosedWorld
  → discoveredByCamera
  → cameraPermission
  → scanningReality
  → waitingForRealTarget
  → walkingBehindRealObject
  → hiddenInReality
```

1. C3 월드가 나타나면 돼지가 “아, 나 좀 그만 쳐다보지. 나 숨고 싶어…”라고 말한다.
2. 나레이션이 끝난 뒤에만 돼지를 탭할 수 있다.
3. 탭하면 `Piggy_running.usdz`의 걷기 애니메이션을 재생하며, 기존 `Cylinder_Tree` 에셋의 카메라 반대편으로 이동한다.
4. 돼지가 나무 뒤에 도착한 뒤 사용자가 C3의 궤도 카메라를 충분히 회전하면, 실제 렌더링에서도 돼지가 드러나는 각도를 확인한다. 이 순간 돼지 모델을 `Piggy_surprised.usdz`로 전환하고 “아, 들켰네… 제대로 숨고 싶은데.” 자막을 동시에 표시한다.
5. 짧은 페이드 전환 뒤 시스템 카메라 권한 요청을 시작한다. 권한을 허용하면 RealityKit 화면을 자동으로 연다.
6. RealityKit 화면은 먼저 실제 공간을 스캔하고 “숨을 물체의 옆면을 탭해줘.”라고 안내한다.
7. 사용자가 실제 물체의 세로 메쉬 면을 탭하면, 돼지는 그 면에서 현재 카메라와 반대가 되는 쪽의 바닥 위치로 걷는다.
8. 실제 메쉬가 초기 시점에서 돼지를 가린다. 사용자가 카메라 위치를 옮겨 반대편을 보면 돼지가 다시 보인다.

## SceneKit 월드

### C3 재사용 경계

`PiggyWorldScene`, `IslandBuilder`, `PigController`, `SceneContainerView`, `AssetLoader`에서 월드를 구성하는 부분을 기준으로 재사용한다. 카메라 궤도·조명·섬 타일·장식물·돼지 모델의 좌표와 애니메이션 동작은 보존한다. SwiftData 모델, 잔액에 따른 크기 변화, 작은 돼지, 이체·입금·Watch 연동 경로는 가져오지 않는다.

월드 코드에는 금융 상태가 없는 작은 어댑터를 둔다. 이 어댑터는 다음 책임만 갖는다.

- C3 섬과 기존 `Cylinder_Tree`를 이름이 있는 씬 노드로 생성한다.
- 돼지의 정지 모델, 걷기 모델, 놀란 모델을 전환한다.
- 카메라 yaw·zoom을 C3와 같은 제스처로 갱신한다.
- 선택한 나무의 경계와 현재 카메라 방향으로 숨는 위치를 계산한다.

돼지의 바깥 노드는 위치·걷기 액션을 맡고, 안쪽 모델 노드는 원본 축 보정·표준 크기를 유지한다. 따라서 모델 교체나 이동 액션이 원본 에셋의 변환을 덮어쓰지 않는다.

### 가짜 숨기와 발견

숨는 좌표는 나무의 월드 경계를 기준으로 현재 카메라에서 멀어지는 방향에 배치한다. 돼지는 나무를 통과하지 않도록 나무의 발자국 바깥에 서고, 화면 중심의 초기 시점에서는 나무가 돼지를 가린다.

발견 상태는 카메라 yaw가 숨기 시작 시점과 충분히 달라지고 돼지가 뷰 프러스텀에 들어온 뒤에만 시작한다. 이 조건과 실제 Simulator 장면 검증을 함께 사용해, 단순한 타이머가 아니라 카메라 회전의 결과로 들켰다는 서사를 유지한다.

발견 순간에는 걷기 모델을 멈추고 `Piggy_surprised.usdz`를 같은 바깥 노드 안에서 보여 준다. 나레이션 오버레이는 모델 전환과 같은 프레임에 나타나며, 페이드 전환이 끝날 때까지 놀란 상태를 유지한다.

## 나레이션과 전환 디자인

새 폰트나 이미지 에셋은 추가하지 않는다. C3의 네이티브 UI 규칙을 따른다.

- SwiftUI 안내·권한 전환 문구: `.system(..., design: .rounded)`의 bold/heavy, 흰색, 얕은 검은 그림자
- SceneKit 위 나레이션: C3의 `overlaySKScene` 방식과 `AvenirNext-Bold` 레이블을 사용하며, 한글은 시스템 폴백을 허용한다.
- 컨테이너: 반투명 어두운 표면 또는 `.ultraThinMaterial`, 둥근 모서리, 짧은 fade/scale 전환
- 색: C3의 하늘·복셀 월드를 가리지 않는 흰색 본문과 낮은 불투명도 검은 그림자. 돼지 핑크와 노란 강조색은 상태 안내에만 사용한다.

SceneKit의 복셀 월드가 페이드아웃하고 시스템 권한 문구가 나타나는 순간을 전환점으로 삼는다. 권한 거부 시에는 이유와 설정으로 가는 방법을 같은 스타일의 안내로 표시하고, RealityKit 세션을 시작하지 않는다.

## RealityKit 실제 숨기

iOS 17을 유지하기 위해 `ARView`를 SwiftUI에 연결한다. 세션 시작 전 `ARWorldTrackingConfiguration.supportsSceneReconstruction(.meshWithClassification)`을 확인한다. 지원 기기에서는 아래 설정을 사용한다.

- 수평·수직 평면 감지
- `sceneReconstruction = .meshWithClassification`
- RealityKit scene understanding의 `.occlusion`, `.collision`, `.physics`, `.receivesLighting`

사용자 탭은 RealityKit 충돌 raycast로 실제 재구성 메쉬를 맞춘다. 선택한 면의 법선이 수직에 가까운 경우만 숨기 대상으로 허용한다. 탁자 윗면처럼 수평인 면, 바닥을 찾지 못하는 위치, 또는 카메라와 너무 가까운 위치는 안내를 표시하고 다시 선택하게 한다.

유효한 탭에서는 표면의 월드 좌표에서 카메라 반대 방향으로 짧게 이동한 후보점을 만든 뒤, 근처의 검증된 수평 평면으로 투영해 돼지의 바닥 위치를 정한다. 돼지는 `Piggy_running` 상태로 후보점까지 이동하고 `Piggy` 정지 모델로 바뀐다. 실제 메쉬는 깊이 버퍼에만 기록되어, 현재 시점의 돼지는 실제 물체 뒤에서 보이지 않는다. 사용자가 물체 옆으로 이동하면 돼지는 다시 렌더링된다.

LiDAR 메쉬 재구성을 지원하지 않는 기기에서는 실제 숨기 단계를 시작하지 않고 지원 기기가 필요하다고 안내한다.

## 검증 기준

### 자동 검증

- C3 월드 어댑터가 기존 나무·돼지·카메라를 이름과 올바른 계층으로 생성한다.
- 나무 뒤 숨기 좌표가 나무의 카메라 반대편이며 돼지의 발이 바닥에 닿는다.
- 경험 상태는 나레이션 완료 전 돼지 탭을 무시하고, 정의된 순서로만 전환한다.
- 카메라 yaw 변화와 프러스텀 조건이 충족되기 전에는 발견 상태가 되지 않는다.
- 발견 상태는 `Piggy_surprised.usdz` 표현과 “아, 들켰네… 제대로 숨고 싶은데.” 자막을 함께 시작한다.
- RealityKit 숨기 좌표 계산은 세로 면·수평 바닥·카메라 방향 입력을 사용하며, 수평 선택과 가까운 선택을 거부한다.
- 기존 C3 원본에서 가져온 에셋은 바이트 단위로 같은지 확인한다.

### 수동 실기기 검증

- LiDAR 지원 기기에서 카메라 권한 요청, 평면·메쉬 스캔, 실제 물체 세로 면 탭을 확인한다.
- 선택한 실제 물체의 현재 카메라 반대편에서 돼지가 가려지는지 확인한다.
- 사용자가 실제로 옆으로 이동했을 때 돼지가 다시 보이는지 확인한다.
- 권한 거부·LiDAR 미지원·수평면 탭·추적 부족의 안내와 복구 경로를 확인한다.

## 문서와 협업

- C3_Piggy는 로컬 참고 원본이다. 재사용한 구조와 에셋 출처, 금융·Watch 기능을 제외한 이유를 저장소 문서에 요약한다.
- `docs/WORK_LOG.md`와 `docs/PROJECT_CONTEXT.md`는 새 흐름과 검증 상태를 갱신한다.
- Draft PR의 후속 보완 항목은 새 설계의 대응 범위에서 정리하고, 구현이 검증되기 전에는 완료로 표시하지 않는다.
- 커밋과 PR에는 작업자·도구·모델 표기를 남기지 않는다.
