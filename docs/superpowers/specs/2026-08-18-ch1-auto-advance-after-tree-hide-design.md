# Chapter 1 C3 자동 진행 설계

## 목적

실기기에서 C3 카메라 yaw·프러스텀 발견 조건이 안정적으로 발화하지 않아, 돼지가 기존 `Cylinder_Tree` 뒤로 이동한 뒤 경험이 멈춘다. 사용자가 돼지를 탭한 뒤 다음 장면으로 확실히 진행할 수 있게 카메라 회전 조건을 제거한다.

## 사용자 흐름

1. 나레이션이 끝난 뒤 사용자가 돼지를 탭한다.
2. 돼지는 기존과 같이 `Piggy_running` 포즈로 `Cylinder_Tree` 뒤까지 걷는다.
3. 나무 도착 뒤 0.40초를 유지한다.
4. 카메라 조작 여부와 무관하게 돼지는 한 번만 `Piggy_surprised`로 전환하고, `아, 들켰네… 제대로 숨고 싶은데.` 자막과 1.5배→1.0배 반응을 실행한다.
5. 기존 `EscapeRootView`는 이 발견 callback을 받아 0.70초 페이드가 끝난 뒤에만 카메라 권한을 요청한다. 허용 뒤 RealityKit 화면으로 자동 전환하는 흐름은 바꾸지 않는다.

## 경계와 상태 전이

- C3 월드만 `pigReachedTree → hiddenInClosedWorld → closedWorldPigDiscovered`를 자동으로 진행한다.
- 자동 발견은 나무 도착 이후에만 한 번 예약한다. 나레이션 전 탭, 이동 중 탭, 이미 발견한 뒤의 예약·카메라 팬은 상태를 건너뛰거나 중복 발견을 만들지 않는다.
- `C3ClosedWorldSceneView`의 팬 제스처는 섬을 둘러보는 역할로 유지하되 더 이상 발견 판단을 호출하지 않는다.
- 전환 기다림은 C3 장면이 해제될 때 취소되어, 사라진 장면의 늦은 callback이 권한 요청·RealityKit 전환을 다시 시작하지 않는다.

## 구현 경계

- `C3ClosedWorld`는 숨기 이동과 숨기 완료 상태를 소유한다.
- `C3ClosedWorldSceneView.Coordinator`는 0.40초 자동 발견 예약과 취소 수명을 소유한다.
- `EscapeRootCoordinator`와 RealityKit의 실제 물체·메쉬·재발견 계약은 변경하지 않는다.
- 새로운 에셋·폰트·금융·저장·Watch 기능은 추가하지 않는다.

## 검증

- 돼지 탭 뒤 나무 도착만으로 자동 발견 callback이 한 번 발생하는 회귀 테스트를 추가한다.
- 카메라를 전혀 돌리지 않아도 놀란 포즈·자막·확대 action이 시작되는지 확인한다.
- 나무 도착 전에는 자동 발견하지 않고, 팬·반복 callback·장면 해제 뒤에는 중복 전환하지 않는지 확인한다.
- 기존 루트 테스트로 발견→페이드 완료→카메라 권한 요청의 순서와 한 번만 요청되는 계약을 유지한다.
- focused XCTest, 전체 XCTest, iPhone 17 Pro Simulator build를 실행한다. 실제 카메라 권한·전환 감각은 `실기기 대기`로 기록한다.
