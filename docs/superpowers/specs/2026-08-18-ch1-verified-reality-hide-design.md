# Chapter 1 — 실제 물체 뒤 숨기 검증 설계

## 목적

실기기에서 “직접 움직여서 피기를 찾아봐.”가 표시됐을 때도 돼지가 카메라 앞에 크게 남아 보였다. 현재 구현은 돼지의 이동 애니메이션 완료를 숨기 완료로 간주하지만, 실제 LiDAR 메쉬가 돼지를 가렸는지는 확인하지 않는다.

이 보수는 사용자가 실제 물체의 옆면을 탭했을 때 돼지가 카메라 쪽에서 출발해 반대편으로 걷는 장면을 보이고, 실제 메쉬에 가려진 것을 확인한 뒤에만 찾기 안내로 전환하게 한다.

## 사용자 경험

1. AR 스캔 화면에서 사용자가 실제 물체의 수직 옆면을 탭한다.
2. 유효한 target이면 돼지는 선택 면의 카메라 쪽 바닥에서 `Piggy_running`으로 나타난다.
3. 돼지는 선택 면의 카메라 반대쪽 바닥 목표까지 걷는다. 안내는 이 동안 “피기가 숨으러 가고 있어.”를 유지한다.
4. 이동이 끝난 뒤 AR 카메라에서 돼지 방향으로 실제 scene-understanding mesh hit-test를 수행한다.
5. mesh가 돼지보다 앞에 있는 것이 확인되면, 돼지를 숨김 완료로 전환하고 “직접 움직여서 피기를 찾아봐.”를 표시한다.
6. 확인되지 않으면 돼지를 현재 면의 반대 방향으로 정해진 짧은 간격만 더 이동하고 같은 검증을 다시 한다. 최대 시도 뒤에도 가려지지 않으면 돼지는 숨김 완료가 되지 않고, 사용자가 더 잘 스캔하거나 다른 물체를 선택하도록 안내한다.

## 설계 경계

- `RealityHidePlanner`는 선택 면·카메라·바닥으로 최초 이동 목표를 계산하는 기존 책임을 유지한다.
- 새 순수 확인 정책은 시작 위치·반대편 목표·검증 결과·시도 횟수로 다음 행동을 고른다. RealityKit API를 직접 호출하지 않아 XCTest로 검증한다.
- `RealityHideARView.Coordinator`는 걷기 완료 후 ARView의 실제 mesh hit 결과를 순수 정책에 전달하고, 그 결과에 따라 다시 걷기·숨김 완료·재선택 안내만 실행한다.
- `EscapeRootCoordinator`의 상태 전이는 `onPigReachedTarget` callback이 실제 가림 확인 뒤에만 전달되므로 변경하지 않는다.
- 스캔 중에 돼지를 scene에 미리 결합하지 않는 카메라 검은 화면 대응은 유지한다. 유효 target 수락 뒤 한 번 결합하는 현재 경계도 유지한다.

## 가림 판정과 재시도

- 검증 ray는 AR 카메라 위치에서 돼지 월드 위치를 향한다.
- `sceneUnderstanding` mesh hit 거리가 돼지까지의 거리보다 안전 여유만큼 작으면 가려진 것으로 판정한다. 기존 재발견 monitor와 동일한 거리 기준을 재사용한다.
- 첫 목적지는 선택 면의 카메라 반대쪽이다. 가림을 찾지 못했을 때만 그 반대 방향으로 한 번씩 더 깊게 이동한다.
- 재시도 횟수와 총 깊이는 제한한다. 임의로 돼지를 멀리 보내거나 floor footprint 밖으로 이동하지 않는다.
- 최대 시도 실패는 `hiddenInReality`로 전이하지 않는다. 돼지를 비활성화해 화면을 가리는 실패 상태를 남기지 않고, 스캔·재선택 안내로 복구한다.

## 오류와 접근성

- running 또는 idle 에셋 로드 실패는 기존의 retryable waiting 상태·고정 오류 안내를 유지한다.
- mesh/floor 정보가 부족하거나 가림 검증이 실패한 경우, 카메라·바닥·물체를 더 스캔하거나 다른 옆면을 탭하라는 안내를 사용한다.
- 실제 가림 확인은 LiDAR 지원 기기의 실기기 관찰이 필요하다. XCTest는 정책·상태 순서·callback 지연만 검증한다.

## 검증

- 순수 정책이 첫 이동 후 가려짐을 확인했을 때만 숨김 완료를 반환하는지 테스트한다.
- 가려지지 않은 첫 확인은 제한된 반대 방향 재이동을 반환하고, 한도를 넘으면 재선택을 반환하는지 테스트한다.
- Coordinator가 이동 완료만으로 `onPigReachedTarget`을 호출하지 않고, 가림 확인 뒤 한 번만 호출하는지 테스트한다.
- 기존 카메라 검은 화면 대응의 scene attachment gate와 실기기 스캔 흐름이 회귀하지 않는지 focused XCTest·전체 XCTest·Simulator build로 확인한다.
- iPhone 16 Pro에서 카메라 표시, 보이는 출발·걷기, 가림 후 찾기 안내, 실제 이동 재발견을 순서대로 수동 확인한다.
